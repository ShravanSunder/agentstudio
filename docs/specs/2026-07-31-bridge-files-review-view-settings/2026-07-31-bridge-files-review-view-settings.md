# Bridge Files and Review View Settings

Date: 2026-07-31

This file is a non-normative entry point. The accepted design contract is split
by responsibility:

- [User Requirements](2026-07-31-bridge-files-review-view-settings-requirements.md)
  owns product Why/What and observable behavior.
- [Program Design](2026-07-31-bridge-files-review-view-settings-program-design.md)
  owns structural How, internal ownership, state, flows, failure behavior, and
  proof seams.

If the documents conflict, implementation must stop. Program Design cannot
change user-facing meaning, and an implementation plan cannot invent either
product meaning or architecture.
