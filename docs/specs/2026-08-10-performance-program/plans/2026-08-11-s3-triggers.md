## Scope and design anchors

- R-INV is the correctness boundary: suppression/coalescing must match the
  ungated sequence at sequence end; deferred work must match at the first
  settled demanded point within one normal interval (Specification
  `R-INV`; Program Design `Admission gates are source-owned`).
- R9-R12 remain owned by `GitWorkingDirectoryProjector`. Extend its existing
  per-worktree pending, quiescence, priority, bounded compute, quarantine,
  circuit-breaker, and pathspec-folding machinery; do not introduce a second
  scheduler, breaker, cache, or projector (Program Design `Slice 3`).
- R11 maps watched-folder scope in `FilesystemGitPipeline`; explicit user
  refresh-all retains its fleet-wide exemption.
- R13 remains part of slice 3 after verification against the actual coverage
  table. `ForgeActor` owns per-repo single-flight, failure backoff, and
  last-published count equality.
- R21 bounds `DarwinFSEventStreamClient` ingress. Overflow is affirmative
  coarse-scope evidence, never an empty/no-change batch.
- R22 keeps `FilesystemProjectionIndex` as affected-key owner and changes
  coordinator sequencing so index intents authorize Bridge product work.
- C1-C4 remain inherited contracts. Slice 3 consumes C1/C2 telemetry and C3
  guard state; it adds no telemetry lifecycle, report resolver, persistence,
  service, command plane, or trust boundary.

## False-green risks and stop/replan conditions

- Targeting watched scans after fleet-wide projector enqueue is too late.
- Union only in the ordinary pending slot is false green; capacity and breaker
  debt must preserve the same paths and conservative flags.
- Equality after publishing Forge facts, or eligibility after starting git
  compute, does not contract the measured waste.
- Dropping an `AsyncStream` element without minting coarse affected-scope debt
  violates R21 even if later periodic refresh happens to repair state.
- Coordinator-side path matching duplicates index ownership and is not R22.
- A mocked provider cannot prove FSEvent ingress, debug product state, or V8.
- Stale markers, state files, historical production samples, or JSONL fallback
  cannot pass current-HEAD performance proof.
- Stop with `[BLOCKER-FOR-PARENT]` for any new persistence/schema, vendor,
  trust/authority boundary, EventBus domain policy, changed public contract,
  weakened proof gate, non-comparable baseline, or ownership move.
